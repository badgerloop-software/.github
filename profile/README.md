# Welcome to Badger Solar Racing!
Welcome to our GitHub organization! 
This organisation contains the **SoFi (Software, Firmware, and Race Strategy)** teams' work for the Electrical team.

## Getting Started

To get access to our repositories:

1. **Message your team lead on Microsoft Teams**  
   Give them your GitHub username and let them know you need access to our organization.
2. Once approved, you’ll receive an **invitation to this organization and relevant repositories**.
